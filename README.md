# Rock-paper-scissors
# 🎮 Rock Paper Scissors Game  

A fun and interactive **Rock Paper Scissors** web game built using **HTML**, **Tailwind CSS**, and **JavaScript**.  
Players can challenge the CPU, select the number of rounds, and enjoy smooth animations and dynamic sound effects.

## 🚀 Features  
- 🎨 Animated player and CPU hands  
- 🧮 Score tracking system  
- 🔢 Selectable number of rounds  
- 🤖 CPU random choice logic  
- 📱 Fully responsive layout using Tailwind CSS  
- 🎵 Background music with user permission popup  
- ✨ Smooth transitions and modern UI

## 🧩 Technologies Used  
- **HTML5**  
- **Tailwind CSS**
